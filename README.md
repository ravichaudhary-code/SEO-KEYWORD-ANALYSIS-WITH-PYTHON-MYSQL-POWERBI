# SEO Keyword Analysis Dashboard

## 📌 Project Overview

This project was completed as part of my Data Analytics Internship.

The objective was to analyze a large SEO keyword dataset, transform raw keyword data into meaningful categories, create a relational database structure, build an interactive Power BI dashboard, and apply machine learning techniques to identify keyword traffic patterns.

---

## 🚀 Tools & Technologies

- Python
- Pandas
- MySQL
- SQL
- Power BI
- Excel
- Machine Learning (K-Means Clustering)

---

## 📊 Dataset

The dataset contains over 25,000 SEO keywords along with metrics such as:

- Search Volume
- Traffic
- CPC (Cost Per Click)
- Keyword Difficulty
- Competition
- Position

---

## 🧹 Data Cleaning & Preprocessing

Performed the following tasks using Python:

- Removed duplicate keywords
- Standardized keyword text
- Handled data inconsistencies
- Prepared data for analysis and reporting

---

## 🔍 Keyword Categorization

Developed custom keyword grouping logic to classify keywords into 15 business categories:

- Project Management
- Scrum & Agile
- Data Analytics
- Business Analyst
- Six Sigma
- Digital Marketing
- Cyber Security
- Python
- Excel
- SQL & Database
- Programming
- AI/ML
- Cloud
- Career
- Others

This enabled category-level SEO analysis and trend identification.

---

## 🗄️ Database Design

Created a relational database model in MySQL consisting of:

### Main Table
- Keyword
- Position
- Previous Position

### Lookup Tables

1. lookup_keyword
2. lookup_search
3. lookup_traffic
4. lookup_metrics

Relationships were created to support structured analytical reporting.

---

## 🤖 Machine Learning

Applied K-Means Clustering using:

- Search Volume
- Traffic

### Why These Variables?

Search Volume represents keyword demand, while Traffic represents actual keyword performance.

The objective was to identify keyword behavior patterns and segment keywords into meaningful clusters.

### Elbow Method

The Elbow Method was used to determine the optimal number of clusters before applying K-Means.

---

## 📊 Key Insights

- Data Analytics and Programming keywords dominate the dataset.
- Cloud-related keywords show high search demand.
- Cyber Security keywords have higher average CPC values.
- Several categories demonstrate moderate-to-high SEO competition.
- Clustering revealed distinct keyword traffic behavior patterns.
